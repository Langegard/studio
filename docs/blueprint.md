# **App Name**: TimeWise Meeting

## Core Features:

- Agenda Input: Input agenda items with intended time allocation.
- Timeline Display: Display agenda items on a horizontal timeline with color-coded sections.
- Real-time Timer: Show time elapsed and remaining as a vertical line moving across the timeline.
- Visual Time Indicator: Indicate passed time by visually 'graying out' sections of the timeline.
- AI Time Management Assistant: Use a tool to alert the meeting leader if agenda items run over time, suggesting options to stay on track (e.g., shorten discussion, postpone to next meeting).

## Style Guidelines:

- Use distinct, calming color palettes for each agenda item (e.g., blues, greens, and soft yellows).
- Implement a gray scale effect for past agenda items as the meeting progresses.
- Accent color: A subtle yet noticeable shade of teal (#4DB6AC) to highlight the active agenda item section.
- Clear and professional font choices (e.g., Open Sans, Lato) for optimal readability in a clinical setting.
- Full-screen, distraction-free layout for focused time tracking.
- Smooth, subtle animations for the timer line and color transitions.
- Use minimal, clear icons for settings, alerts, or additional information, following a flat design style.
